# ml-from-np
This repository serves as a personal exercise for coding and machine learning in NumPy, to better understand how ML works from first principles.

# Contents
## Logistic Regression
Basic version of a binary logistic regression classifier. Includes:
- Iris dataset (simplified to classifying one species)
- Full model (logistic function + log-likelihood error + parameter estimation using basic gradient descent)
- Predictions on iris dataset
- Typical classification metrics (on cross-validated train/test sample): prediction, recall, F1 score
